### 📝 **About This Blog**

A curated collection of notes and reflections, built from my Obsidian vault and published using **[Quartz](https://github.com/jackyzha0/quartz)**.

**Features:**

- 📚 Knowledge management with Obsidian
- 🔗 Bi-directional linking between notes
- 💬 Discussion via Giscus on every page
- 🎨 Clean, responsive design
- 🔍 Full-text search capabilities

---

### 📂 Repository Structure

```bash
Sisyphus-Mountain/
├── content/          # All blog posts (from Obsidian)
├── quartz/           # Quartz static site generator
├── public/           # Generated static website
└── .github/workflows/# GitHub Actions for auto-deployment
```

---

### 🗣️ Join the Conversation

Each blog post is connected to a GitHub Discussion via **Giscus**. Feel free to share your thoughts, ask questions, or continue the conversation there!
